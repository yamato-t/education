## **課題①　等速で移動して壁に到達するまでのカウントダウンを表示してください**

`Space` キーで等速運動を開始し、  
壁に到達するまでの残りフレーム数をカウントダウン表示する処理を作成してください。

- 移動役の Cube と、x = 30 の位置に壁役の Cube を配置する
- 移動量 `speed`（1 フレームあたり 0.1）と、壁までの距離 `distance`（30）を変数として持たせる
- `Space` キーを押した瞬間に、壁に到達するまでのフレーム数を `distance` と `speed` から計算する
- 毎フレーム x 軸方向に `speed` を加算して移動する
- 残りフレーム数を毎フレーム `Debug.Log` または UI のテキストで表示する
- 壁に到達したら → **開始位置に戻して停止する**
- カウントが 0 になるフレームと、壁に到達するフレームが一致することを確認する

`speed` と `distance` を Inspector から変更しても、  
カウントダウンと到達のタイミングが一致し続けることを確認してください。

## **課題②　加速しながら移動する場合のカウントダウンを表示してください**

課題①の移動を等加速度運動に変更し、  
壁に到達するまでのフレーム数を**移動開始前に**計算してください。

- 初速 `v0`（0.1）と加速度 `a`（1 フレームごとに 0.01 増加）を変数として持たせる
- 毎フレーム速度に `a` を加算し、その速度を座標に加算して移動する
- `Space` キーを押した瞬間に、変位の公式 $x=v_{0}t+\frac{1}{2}at^2$ を使って到達フレーム数 $t$ を計算する
  - $t$ についての二次方程式を解く形になる
  - 平方根の計算には `Mathf.Sqrt` を使う
- 計算したフレーム数からカウントダウンを表示する
- 実際に壁に到達したフレーム数も `Debug.Log` で表示し、計算結果と比較する

計算結果と実際の到達フレームが数フレームずれる場合は、  
「速度を加算する」処理と「座標に加算する」処理の順番を入れ替えて結果がどう変わるか試し、  
ずれが生じる理由をコメントとしてスクリプトに書いてください。

## **課題③　停止線ぴったりで止まる車を作成してください**

一定の速度で走っている車が、ブレーキをかけて  
**指定した停止線ぴったりで止まる**処理を作成してください。

- 車役の Cube と、停止線役の薄い Cube を配置する
- 車は初速 `v0`（1 フレームあたりの移動量）で x 軸方向に等速で走り続ける
- `B` キーを押した瞬間に、その時点の車の位置から停止線までの距離 `x` を計算する
- 公式 $v^2-{v_{0}}^2=2ax$ を使い、停止線で速度が 0 になる加速度 `a` を計算する
  - 減速なので → **`a` はマイナスの値になる**
- 以降は毎フレーム速度に `a` を加算し、速度が 0 以下になったら → **停止する**
- 停止した位置と停止線の位置の差を `Debug.Log` で表示する

`B` キーを押すタイミングや `v0` を変えても、  
停止線付近で止まることを確認してください。

## **課題④　フレームレートが変わっても同じ動きにしてください**

課題②の等加速度運動を、**1 フレームあたり**ではなく  
**1 秒あたり**の単位で動くように作り直してください。

- 初速と加速度を秒単位（$\mathrm{m/s}$・$\mathrm{m/s^2}$）に換算した値で変数に設定する
  - 60fps で課題②と同じ動きになる値に換算する
- 前フレームからの経過時間 `Time.deltaTime` を使って、速度と座標を更新する
- 到達までの時間を秒単位で計算し、残り秒数をカウントダウン表示する
- `Application.targetFrameRate` を 30 と 60 に切り替えて実行する
  - どちらも → **ほぼ同じ時間で壁に到達する**
- 課題②のスクリプトでも同じように切り替え、到達時間がどう変わるか比較する

課題②と課題④で、フレームレートによる到達時間の違いを  
`Debug.Log` で表示して確認してください。
