# **課題**

---

## **課題①　キー入力でプレイヤーを移動させてください**

Unity で Cube をプレイヤーとして配置し、  
キー入力に応じて移動ベクトルを座標に加算する処理を作成してください。

- シーンに Cube を 1 つ配置し、移動用のスクリプトをアタッチする
- `Update` 内でキー入力を確認し、移動ベクトル `(x, y, z)` を作成する
  - `W` → **奥（z が増える方向）**
  - `S` → **手前（z が減る方向）**
  - `A` → **左（x が減る方向）**
  - `D` → **右（x が増える方向）**
- 作成した移動ベクトルを `transform.position` に加算して移動する
- キーを離すと停止することを確認する

`W` と `D` を同時に押したとき、  
1 キーだけのときより移動が速くなっていないかも確認してください。

## **課題②　敵を 60 フレームで目的地まで移動させてください**

指定した目的地まで、距離に関係なく  
**必ず 60 フレームで到着する**移動処理を作成してください。

- 敵役の Cube と、目的地役の空の GameObject を配置する
- `Space` キーを押した時点の位置から、目的地へ向かう移動ベクトルを減算で計算する
- 計算したベクトルを 60 分割し、1 フレームあたりの移動量とする
- 毎フレーム移動量を加算し、60 フレーム経過したら停止する
- 目的地を近い位置・遠い位置に置き換えて試す
  - どちらも → **同じ時間で到着する**
  - 遠いほど → **移動速度が速くなる**

## **課題③　プレイヤーを一定速度で追いかける敵を作成してください**

プレイヤーとの距離に関係なく、  
**常に同じ速さ**でプレイヤーを追いかける敵を作成してください。

- 課題①のプレイヤーと、敵役の Cube を配置する
- 敵の移動速度（1 フレームあたりの移動量）を変数 `speed` として持たせる
- 毎フレーム、敵からプレイヤーへ向かうベクトルを計算する
- 三平方の定理と `Mathf.Sqrt` で二点間の距離を計算する
- 距離を使ってベクトルを正規化し、`speed` を乗算して敵の座標に加算する
- 距離が `speed` 以下になったら → **移動を止める**
- `speed` の値を Inspector から変更し、追いかける速さが変わることを確認する

`Vector3.normalized`・`Vector3.magnitude`・`Vector3.Distance`・  
`Vector3.MoveTowards` は使わず、自分で計算してください。
