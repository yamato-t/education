# **課題**

重力加速度 $g$ は $9.8\hspace{2pt}\mathrm{m/s^2}$ とし、  
60fps 前提で 1 フレームあたりの値に換算して使用してください。  
Unity の `Rigidbody`（物理演算）は使わず、自分で計算してください。

---

## **課題①　指定した高さから物体を自由落下させてください**

指定した高さから物体を落とし、  
**地面（y = 0）に到達するまでの残りフレーム数**をカウントダウン表示してください。

- 落下させる Sphere と、地面役の薄い Cube（上面が y = 0）を配置する
- 落下開始の高さ `height` を変数として持たせ、Inspector から変更できるようにする
- 重力加速度 `g` を 1 フレームあたりの値に換算して変数に設定する
- `Space` キーを押したら、Sphere を `height` の位置に置いて落下を開始する
- 落下開始の瞬間に、公式 $t = \sqrt{\frac{2h}{g}}$ を使って地面までのフレーム数を計算する
- 毎フレーム速度に `g` を加算し、その速度で y 座標を下げる
- 残りフレーム数を毎フレーム `Debug.Log` または UI のテキストで表示する
- y が 0 以下になったら → **y = 0 に補正して停止する**
- 計算したフレーム数と、実際に着地したフレーム数を `Debug.Log` で表示して比較する

`height` を 5・10・20 と変えて、  
計算結果と実際の着地フレームがほぼ一致することを確認してください。

## **課題②　その場で垂直ジャンプするキャラクターを作成してください**

地面に立っているキャラクターが、  
`Space` キーで**真上にジャンプして地面に戻る**処理を作成してください。

- キャラクター役の Cube を地面の上に配置する
- ジャンプの初速 `v0`（1 フレームあたりの移動量）を変数として持たせる
- `Space` キーを押したら、y 方向の速度に `v0` を設定してジャンプを開始する
- 毎フレーム y 方向の速度から `g` を引き、その速度で y 座標を更新する
  - 上昇中 → **速度はプラス**
  - 頂点を過ぎた後 → **速度がマイナスに反転して落下する**
- 着地したら → **y = 0 に補正し、速度を 0 にして停止する**
- ジャンプ中に `Space` キーを押しても → **二段ジャンプしない**
- ジャンプ開始時に公式 $t = \frac{2v_{0}}{g}$ で滞空フレーム数を計算し、実際の滞空フレーム数と比較する

`v0` を変更して、ジャンプの高さと滞空時間が  
どのように変わるか確認してください。

## **課題③　移動しながらジャンプし、着地点を予測してください**

課題②のキャラクターを、**ジャンプ中も水平移動できる放物運動**に拡張し、  
ジャンプした瞬間に着地点を表示してください。

- `WASD` キーで XZ 平面上を一定の速度で移動できるようにする
- `Space` キーを押した瞬間の水平の移動量（XZ ベクトル）を保持する
- ジャンプ中は、保持した XZ ベクトルで水平に等速移動し続ける
  - ジャンプ中にキー入力を変えても → **水平の移動量は変わらない**
- 垂直方向（Y）は課題②と同じ処理で動かす
- ジャンプした瞬間に、滞空フレーム数と XZ ベクトルから着地点を計算する
- 着地点に目印役の薄い Cube（または Sphere）を表示する
- 実際に着地したら、目印の位置との差を `Debug.Log` で表示する

水平の移動と垂直の移動は、  
それぞれ独立した変数で管理してください。

## **課題④　ジャンプの最高到達高度を指定できるようにしてください**

課題③のジャンプを、初速ではなく  
**最高到達高度 `maxHeight` を指定する方式**に作り直してください。

- `maxHeight`（m）を変数として持たせ、Inspector から変更できるようにする
- `v0` は Inspector から指定せず、`maxHeight` と `g` から計算で求める
  - 頂点では → **y 方向の速度が 0 になる**ことを利用する
  - 03.運動で扱った等加速度運動の公式から、`v0` を求める式を自分で導く
- ジャンプ中の y 座標の最大値を記録し、着地時に `Debug.Log` で `maxHeight` と比較する
- 課題③の着地点予測も、計算した `v0` で引き続き動作させる

導いた式は、途中の変形も含めて  
スクリプト内にコメントとして書いてください。
