# **課題**

`transform.LookAt`・`Quaternion.LookRotation`・`Mathf.Rad2Deg` は使わず、
自分で計算してください。

---

## **課題①　プレイヤーの周りを回る衛星を作成してください**

プレイヤーを中心に、一定の半径で  
**ぐるぐると回り続ける衛星（オプション）**を作成してください。

- プレイヤー役の Cube と、衛星役の Sphere を配置する
- 衛星に半径 `radius` と回転速度 `speed`（1 フレームあたりの角度・度数法）を変数として持たせる
- 毎フレーム角度に `speed` を加算する
- 角度を度数法から弧度法（ラジアン）に変換する
- `Mathf.Cos`・`Mathf.Sin` と `radius` で XZ 平面上の位置を計算する
  - x → **`radius` × cosθ**
  - z → **`radius` × sinθ**
- 計算した位置にプレイヤーの座標を加算し、衛星の `transform.position` に設定する
- プレイヤーを移動させても → **衛星がプレイヤーの周りを回り続ける**

度数法から弧度法への変換は `Mathf.Deg2Rad` を使わず、  
`Mathf.PI` を使って自分で計算してください。

## **課題②　砲台の発射方向を回転させて弾を撃ってください**

砲台が向いている方向ベクトルを、キー入力で回転させ、  
その方向へ弾を発射する処理を作成してください。

- 砲台役の Cube を配置し、発射方向ベクトル `dir`（初期値 `(1, 0, 0)`）を持たせる
- `Debug.DrawRay` で砲台から `dir` の方向に線を描画し、向きを確認できるようにする
- キー入力で `dir` を 1 フレームあたり 2 度ずつ回転させる
  - `Q` → **左回り（反時計回り）**
  - `E` → **右回り（時計回り）**
- 回転は加法定理の式を使い、`dir` の x と z から新しい x と z を計算する
- `Space` キーを押したら弾役の Sphere を生成し、その時点の `dir` の方向へまっすぐ移動させる

「今の角度」を変数で保持してはいけません。  
`dir` のベクトルだけを使って回転させてください。  
また `Quaternion` や `transform.Rotate` は使用しないでください。

## **課題③　プレイヤーの方向を向く敵を作成してください**

プレイヤーがどこに移動しても、  
**常にプレイヤーの方向へ体を向ける敵**を作成してください。

- 01.平行移動の課題①で作成したプレイヤーと、敵役の Cube を配置する
- 敵の正面が分かるように、敵の子オブジェクトとして小さな Cube を +Z 側に付ける
- 毎フレーム、敵からプレイヤーへ向かうベクトルを計算する
- `Mathf.Atan2` を使ってベクトルの角度（ラジアン）を求める
- 求めた角度を度数法に変換し、敵の `transform.eulerAngles` の Y に設定する
- プレイヤーを敵の周りで一周させても → **敵の正面が常にプレイヤーを向いている**

`Mathf.Atan2` に渡す引数の順番に注意してください。
