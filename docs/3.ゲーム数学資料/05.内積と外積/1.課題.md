# **課題**

内積・外積の計算は自分で関数を作成して使用してください。  
Unity の `Vector3.Dot`・`Vector3.Cross` は、  
自作関数の結果と比較して確認する目的でのみ使用してください。  
`Vector3.Angle`・`Vector3.Project`・`Transform.LookAt` などの  
角度や向きを直接求める関数は使わず、自分で計算してください。

---

## **課題①　内積を計算する関数を作成し、二つのベクトルのなす角度を表示してください**

二つのベクトルの内積を計算する関数を自作し、  
その結果から**二つのベクトルのなす角度**を求めて表示してください。

- 二つの `Vector3` を受け取り、内積を `float` で返す関数 `Dot` を作成する
  - 計算式 $A_{1}B_{1}+A_{2}B_{2}+A_{3}B_{3}$ をそのまま実装する
- 二つのベクトル `a` `b` を変数として持たせ、Inspector から変更できるようにする
- `a` `b` を正規化（単位ベクトル化）してから `Dot` で内積を計算する
- 内積の結果を `Mathf.Acos` で角度（ラジアン）に変換し、度数法に直して表示する
- 自作 `Dot` の結果と `Vector3.Dot` の結果を `Debug.Log` で並べて表示する
- 以下の組み合わせで、内積と角度が想定どおりになることを確認する
  - 同じ向き（例：`(1, 0, 0)` と `(2, 0, 0)`） → **内積 1・角度 0 度**
  - 直交（例：`(1, 0, 0)` と `(0, 0, 1)`） → **内積 0・角度 90 度**
  - 正反対（例：`(1, 0, 0)` と `(-1, 0, 0)`） → **内積 -1・角度 180 度**

正規化せずに内積を計算した場合、  
`Mathf.Acos` の結果がどうなるかも試し、理由をコメントとしてスクリプトに書いてください。

## **課題②　プレイヤーの前方にいる敵だけをロックオン対象にしてください**

プレイヤーの向きを基準に、  
**左右 `viewAngle` 度の範囲内にいる敵だけ**をロックオン対象として色を変えてください。

- プレイヤー役の Cube と、敵役の Sphere を 5 個以上配置する
- プレイヤーは `A` `D` キーで Y 軸回転、`W` キーで前進できるようにする
- 視野の片側の角度 `viewAngle`（例：30 度）を変数として持たせる
- 毎フレーム、以下の手順で敵ごとに判定する
  - プレイヤーの前方向ベクトルを求めて正規化する
  - プレイヤーから敵への方向ベクトルを求めて正規化する
  - 二つのベクトルの内積を課題①の `Dot` で計算する
  - 内積と $\cos(\mathrm{viewAngle})$ を比較する
- 視野の範囲内にいる敵 → **赤色にする**
- 視野の範囲外にいる敵 → **白色に戻す**
- 判定に `Mathf.Acos` を使わず、内積の値のまま比較する

視野の境界線を `Debug.DrawLine` などで表示し、  
敵が境界線をまたいだ瞬間に色が切り替わることを確認してください。

## **課題③　直線上で点に最も近い位置を求めてください**

内積による**射影**を使い、  
直線と点の最短距離、および直線上で点に最も近い位置を求めてください。

- 直線の始点役の Sphere `start` と終点役の Sphere `end` を配置する
- 直線から離れた位置に、点役の Sphere `point` を配置する
- 最近点を表示する目印役の小さな Sphere を配置する
- 毎フレーム、以下の手順で計算する
  - `start` から `end` へのベクトルを正規化し、直線の向き `dir` とする
  - `start` から `point` へのベクトル `v` を求める
  - `v` と `dir` の内積で、`dir` 方向に沿った `v` の長さ（射影の長さ）を求める
  - `start` から `dir` 方向へ射影の長さだけ進んだ位置を最近点とする
- 目印を最近点の位置に移動する
- `point` と最近点の距離を最短距離として `Debug.Log` で表示する
- `start` と `end` の間を `Debug.DrawLine` で表示する

実行中に `point` を Scene ビューで動かし、  
目印が常に直線上にあり、`point` との線分が直線と直交していることを確認してください。

## **課題④　外積を計算する関数を作成し、敵が左右どちらにいるか判定してください**

二つのベクトルの外積を計算する関数を自作し、  
**敵がプレイヤーの左右どちらにいるか**を判定してください。

- 二つの `Vector3` を受け取り、外積を `Vector3` で返す関数 `Cross` を作成する
  - 資料の計算式をそのまま実装する
- 自作 `Cross` の結果と `Vector3.Cross` の結果を `Debug.Log` で並べて表示する
- 同じベクトル同士で外積を計算し → **ゼロベクトルになる**ことを確認する
- 課題②のシーンを使い、プレイヤーの前方向ベクトルと敵への方向ベクトルの外積を計算する
- 外積の結果の y 成分の符号で判定する
  - 敵が右側にいる → **青色にする**
  - 敵が左側にいる → **黄色にする**
- 課題②のロックオン判定（赤色）と組み合わせ、優先順位を自分で決めて実装する

Unity は左手座標系のため、  
右側・左側で y 成分の符号がどちらになるかを実際に確かめ、  
その結果をコメントとしてスクリプトに書いてください。

## **課題⑤　ターゲットの方向へ少しずつ旋回する砲台を作成してください**

内積で**回転する角度**を、外積で**回転する方向**を求め、  
砲台がターゲットの方向へ少しずつ旋回する処理を作成してください。

- 砲台役の Cube（向きが分かるよう砲身役の細長い Cube を子に付ける）を配置する
- ターゲット役の Sphere を配置し、矢印キーで XZ 平面上を移動できるようにする
- 1 フレームあたりの最大旋回角度 `turnSpeed`（例：2 度）を変数として持たせる
- 毎フレーム、以下の手順で砲台を Y 軸回転させる
  - 砲台の前方向ベクトルとターゲットへの方向ベクトルを求めて正規化する
  - 内積から、二つのベクトルのなす角度を求める
  - 外積の y 成分の符号から、右回り・左回りのどちらに回転するかを決める
  - なす角度が `turnSpeed` より大きい → **`turnSpeed` だけ回転する**
  - なす角度が `turnSpeed` 以下 → **なす角度の分だけ回転してぴったり向く**
- 砲台が常に**近い側の向き**から回り込んでターゲットを向くことを確認する

ターゲットを砲台の真後ろ付近に移動させた場合の動きも確認し、  
問題が起きる場合は原因と対処をコメントとしてスクリプトに書いてください。
