## **課題①　複数のスレッドでメッセージを表示するプログラムを作成してください**

`std::thread` を使ってスレッドを作成し、  
メインスレッドとは別に処理が動くことを確認してください。

- 引数で受け取った名前と回数を使い、メッセージを繰り返し表示する関数を作成する
- `main` で 2 つの `std::thread` を作成し、それぞれ異なる名前と回数を渡す
- 両方のスレッドを `join()` で待機してから `main` を終了する
- 何度か実行し、表示される順番が毎回同じとは限らないことを確認する

`join()` を呼ばなかった場合にどうなるかも試してみてください。

## **課題②　データ競合を発生させ、ミューテックスで回避するプログラムを作成してください**

複数のスレッドから同じ変数を書き換え、  
データ競合が起きる様子と、その回避方法を確認してください。

- グローバル変数 `counter` を `0` で初期化する
- `counter` を 100000 回 `++` する関数を作成する
- 2 つのスレッドでその関数を同時に実行し、終了後に `counter` の値を表示する
  - 期待値（200000）にならない場合があることを確認する
- `std::mutex` と `std::lock_guard` を使って書き換え部分を保護する
  - 何度実行しても → **200000** になることを確認する

## **課題③　口座間の送金処理でデッドロックを発生させ、回避するプログラムを作成してください**

2 つの銀行口座の間でお金を送り合う処理を作り、  
デッドロックが起きる原因と回避方法を確認してください。

- `id`（口座番号）・`balance`（残高）・`std::mutex` を持つ `Account` 構造体を作成する
- 口座 A（`id` = 1、残高 10000）と口座 B（`id` = 2、残高 10000）を用意する
- 送金関数 `transfer(Account& from, Account& to, int amount)` を作成する
  - `from` → `to` の順に両方の口座のミューテックスをロックする
  - `from` の残高から `amount` を引き、`to` の残高に `amount` を足す
- スレッド 1 で A → B へ 1 円の送金を 10000 回行う
- スレッド 2 で B → A へ 1 円の送金を 10000 回行う
- 処理が止まったまま進まなくなることを確認する
  - 発生しにくい場合は、1 つ目のロックの後に `std::this_thread::sleep_for` で少し待つ
- `transfer` を修正し、送金の向きに関係なく **`id` が小さい口座から先にロックする** ようにする
- 最後まで処理が完了し、両方の残高が → **10000** に戻っていることを確認する
